# Infinite-Canvas
Supports comfyui/API calls/modelscope calls

功能特性：
1. 画布功能全新升级，支持Agent/一键分层/多人协同/共享画布/免费公网图床
2. 软件内即可启动ComfyUI/映射工作流等
3. 海量免费APP可下载
4. 全新的账号管理/APP权限系统
5. 提供开发者模式，可以开发自己公司的业务软件离线运行
